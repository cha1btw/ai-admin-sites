# ZapysAI — редизайн 24.10.2026

Оновлено існуючий статичний лендинг у `landing/`. Збережено Vercel Root Directory `landing`, п'ять мов, темну тему, форму з наявним API-контрактом, демо запису та передачі людині, калькулятор і додаткові послуги.

## Дизайн

Теплий молочний фон, глибока слива, лаванда й спокійний зелений. Manrope для тексту та заголовків, Georgia Italic для коротких акцентів. Нова аватарка у `landing/assets/avatar.png`. Стилі у `landing/zapysai.css`; додані тексти п'ятьма мовами у `landing/zapysai-content.js`.

Додано вісім сфер бізнесу, запуск за чотири кроки, блок характеристик у цифрах та прозору примітку про припущення калькулятора. Числа 24/7, 14 днів і 1–3 дні взяті з наявного лендингу; це характеристики пропозиції, а не статистика клієнтських результатів.

## Тарифи, надані власником

- Lite: 2 499 грн / місяць; 20 000 грн / рік. EUR: 100 / місяць; 900 / рік.
- Medium: 3 999 грн / місяць; 32 000 грн / рік. EUR: 160 / місяць; 1 440 / рік.
- Pro: 6 999 грн / місяць; 56 000 грн / рік. EUR: 200 / місяць; 1 800 / рік.

Для всіх — 14 днів безкоштовно. Складна інтеграція бази знань Pro може потребувати разового налаштування приблизно за 300 EUR. Гривня та EUR — окремі запропоновані ціни, а не валютна конвертація. Ціни в PLN прибрано: нових сум власник не надавав. Польська мова використовує EUR за замовчуванням, валюту можна обрати незалежно від мови.

Годова оплата показує повну суму до сплати за рік, приблизний еквівалент на місяць та точну економію проти 12 місячних платежів. Калькулятор порівнює тариф Medium за поточними валютою та періодом оплати, оцінює виручку, а не прибуток, і не гарантує відновлення втрачених записів.

Правила повернення коштів за річну передплату власник ще не визначив. На сайті вказано, що умови оплати й скасування погоджуються до підключення; безумовне повернення коштів не обіцяється.

Перелік можливостей тарифів — комерційна специфікація, надана власником. Цей репозиторій містить лише сайт; функції бота, CRM, Viber, WhatsApp і платежі тут не реалізуються.

## Перед використанням форми

Адреса `apiBase` залишається порожньою, а `demoBot` — заглушкою. За подальшою вказівкою власника контакт налаштовано на `@ZapysAI`. Без API форма готує текст заявки та посилання на чат Telegram з чернеткою; відвідувач має сам підтвердити надсилання в Telegram. Є копіювання як запасний варіант. Сайт не показує непідтверджене «заявку отримано». З увімкненим API збережено контракт `POST /leads`, а тариф, період, валюта та обраний контекст додаються до `message`.

## Наступні поліпшення конверсії

Додано приклади діалогів для восьми сфер, пояснюваний підбір найменшого відповідного тарифу за двома запитаннями та видимий підсумок перед заявкою. Обов'язкові поля — ім'я і контакт; необов'язкові деталі згорнуто. Підбір пропонує Lite для одного текстового каналу, Medium для аудіо/нагадувань/аналітики, Pro для кількох каналів або передоплат/листа очікування/бази знань. Клієнт може обрати інший тариф самостійно.

Це гіпотези поліпшення зручності, а не обіцянка зростання конверсії. Застосовано [progressive disclosure від NN/g](https://www.nngroup.com/articles/progressive-disclosure/). [Дослідження Baymard щодо полів](https://baymard.com/research-articles/required-optional-form-fields) стосується checkout, тому його числові результати не переносяться на цей лендинг. Не додавали вигаданих відгуків, статистики, дефіциту чи таймерів.

Див. [LEADS.md](LEADS.md) для приймання заявок і [tests/](tests/) для повторення перевірок: `npm ci --prefix tests && npm test --prefix tests`.

## Джерело автоматичної генерації

README початкового репозиторію повідомляє, що `landing/` генерується з приватного репозиторію бота через `scripts/build_sites.py`. Власник прямо попросив змінити цей репозиторій, тому редизайн підготовлено тут. Щоб наступна генерація його не перезаписала, потрібно перенести всі файли `landing/`, включно з `conversion.js`, `conversion-copy.js`, `conversion.css` та аватаркою, до джерела/шаблону приватного репозиторію та включити їх до копіювання. Приватне джерело в цій роботі недоступне.

## Перегляд

З кореня репозиторію: `python3 -m http.server 4173 --directory landing`. Збірка не потрібна. Шрифти та іконки завантажуються з Google Fonts і jsDelivr; у разі блокування шрифту працює системний запасний шрифт.

Браузерну візуальну перевірку в цій сесії не завершено: доступ до локального URL було відхилено. Результати перевірки коду, цін, перекладів та форми наведено в передачі роботи.
