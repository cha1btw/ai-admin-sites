# Как теперь принимаются заявки ZapysAI

Контакт настроен на **@ZapysAI**: https://t.me/ZapysAI.

## Что делает посетитель

1. При желании выбирает свою сферу и подбирает тариф.
2. Вводит имя и контакт. Бизнес и комментарий необязательны.
3. Нажимает «Подготовить заявку» и проверяет готовый текст.
4. Нажимает «Открыть Telegram». Откроется чат @ZapysAI с черновиком сообщения.
5. Нажимает «Отправить» уже в Telegram. После этого сообщение приходит вам в обычный чат.

Текст включает имя, контакт, выбранный тариф, полную цену за выбранный период, сферу и пожелания. Если клиент Telegram не перенёс черновик, посетитель может скопировать текст кнопкой и вставить вручную. Без JavaScript остаётся прямая ссылка на @ZapysAI; форма не отправляет контактные данные в URL вашего сайта.

Ссылка с черновиком соответствует [официальной документации Telegram](https://core.telegram.org/api/links#public-username-links). Она не отправляет сообщение автоматически. Сайт не утверждает, что заявка получена, и не считает открытие чата подтверждением отправки.

## Что проверить владельцу

- @ZapysAI должен быть вашим доступным для переписки аккаунтом, а не каналом без личных сообщений.
- Уведомления о новых личных сообщениях должны быть включены в вашем Telegram, если вы хотите получать их сразу.
- Для проверки можно самостоятельно подготовить заявку и отправить её с другого своего аккаунта. Агент тестовые сообщения от вашего имени не отправлял.

Отдельный сервер или секретный токен для этого способа не нужны. Персональные данные формы не сохраняются в localStorage, не попадают в события аналитики и не отправляются в фоновый API. Их передача в Telegram происходит при явном переходе посетителя в чат.

## Если позже понадобится автоматическая отправка прямо из формы

Это другой режим: потребуется рабочий серверный endpoint `POST /leads`, который принимает `name`, `contact`, `business`, `service`, `message`, `website`, `source`. Его адрес задаётся в `window.CONFIG.apiBase` в `landing/index.html`. Сайт автоматически переключится на отправку через API и покажет подтверждение только после успешного ответа сервера.

Если endpoint уведомляет Telegram-ботом, токен бота и ID чата нужно хранить только в серверных переменных окружения. Не добавляйте их в HTML, клиентский JavaScript или публичный репозиторий. Для текущего приёма в личный чат @ZapysAI бот не создавался и токены не запрашивались.

## Как измерять результат

Скрипт создаёт локальные события `zapysai:conversion`: `industry_example`, `plan_recommendation`, `recommended_plan_selected`, `lead_draft_prepared`, `telegram_chat_opened`. Они не отправляются во внешнюю аналитику автоматически и не содержат имя, телефон или текст заявки. При подключении аналитики отделяйте открытия чата от реально полученных заявок. Рост конверсии не обещан: его нужно проверять на реальном трафике.
